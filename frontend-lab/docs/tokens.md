# Design tokens

Raw tokens are the source values switched by the `data-theme` attribute. Tailwind aliases expose the same values through utility classes.

| Token | Light value | Dark value | Usage |
| --- | --- | --- | --- |
| `--bg` | `#f8fafc` | `#0b1220` | Page background; Tailwind `bg-bg` |
| `--surface` | `#ffffff` | `#131c2e` | Cards and navigation; `bg-surface` |
| `--text` | `#0f172a` | `#e2e8f0` | Main text; `text-fg` |
| `--muted` | `#64748b` | `#94a3b8` | Secondary text; `text-muted` |
| `--primary` | `#0ea5e9` | `#38bdf8` | Accent and primary actions; `bg-primary` |
| `--primary-contrast` | `#ffffff` | `#06202e` | Text on primary actions; `text-primary-contrast` |
| `--border` | `#e2e8f0` | `#243049` | Dividers and outlines; `border-line` |
| `--radius` | `0.75rem` | `0.75rem` | Component corners; `rounded-card` |
| `--color-bg` | `#f8fafc` | `#0b1220` | Tailwind alias for `--bg` |
| `--color-surface` | `#ffffff` | `#131c2e` | Tailwind alias for `--surface` |
| `--color-fg` | `#0f172a` | `#e2e8f0` | Tailwind alias for `--text` |
| `--color-muted` | `#64748b` | `#94a3b8` | Tailwind alias for `--muted` |
| `--color-primary` | `#0ea5e9` | `#38bdf8` | Tailwind alias for `--primary` |
| `--color-primary-contrast` | `#ffffff` | `#06202e` | Tailwind alias for `--primary-contrast` |
| `--color-line` | `#e2e8f0` | `#243049` | Tailwind alias for `--border` |
| `--radius-card` | `0.75rem` | `0.75rem` | Tailwind alias for `--radius` |
| `--font-sans` | `"Inter", system-ui, sans-serif` | `"Inter", system-ui, sans-serif` | Default sans-serif font |
